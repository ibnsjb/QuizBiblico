# Quiz Bíblico IBNS

## Projeto
App de controle de Quiz Bíblico para a Igreja Batista Nova Sião (IBNS).
- Usuário: Kinho (líder de multimídia)
- Domínio: ibnovasiao.com.br

## Stack
- Next.js 14 (App Router) + Firebase Realtime Database
- Tailwind CSS 3
- Framer Motion para animações
- Web Audio API para sons (sem arquivos externos)

## Design
- Dark theme inspirado no "Show do Milhão"
- Cores: #0a0e27 (dark), #ffd700 (gold), #00c853 (green), #d32f2f (red), #7c4dff (purple), #ff6d00 (orange)
- Fonts: DM Sans, Plus Jakarta Sans, JetBrains Mono

## Arquitetura
- Firebase Realtime DB (sem Prisma/PostgreSQL)
- Dois modos: Apresentador (controle total) e Público (leitura)
- Modo salvo no localStorage
- Sessões com nome + data, múltiplas simultâneas
- Acesso apresentador: dupla confirmação (sem senha)

## Funcionalidades
- Sessões, grupos (nome editável), sorteio de ordem
- Rodadas sequenciais com acerto/erro
- 4 ajudas: Eliminar Resposta, Ajuda da Igreja, Consultar Bíblia, Dobrar Acerto
- Pontuação progressiva por faixas configuráveis
- Desempate: mata-mata, encerrar empatado, ou sortear ganhador
- Sons: acerto, erro, shuffle, ajuda, double, winner, tiebreaker
- Botão mudo global

## Firebase Env Vars
NEXT_PUBLIC_FIREBASE_API_KEY, AUTH_DOMAIN, DATABASE_URL, PROJECT_ID, STORAGE_BUCKET, MESSAGING_SENDER_ID, APP_ID

## Projeto: Quiz Bíblico IBNS

### Visão geral
App web (Next.js) para quiz bíblico ao vivo da Igreja Batista Nova Sião (IBNS), inspirado no "Show do Milhão" (dark theme azul escuro/dourado/verde/vermelho). Substitui o painel antigo em ibnovasiao.com.br/quiz. Usuário: Kinho (líder de multimídia).

### Tecnologia
- Next.js App Router + Firebase Realtime Database (sincronização em tempo real)
- Firebase config via env vars NEXT_PUBLIC_FIREBASE_* no .env. Projeto Firebase: quizbiblico-425fe. Credenciais já configuradas.
- Deploy planejado: Vercel + GitHub, domínio ibnovasiao.com.br
- lib/firebase.ts inicializa só no client quando configurado; lib/firebase-operations.ts tem todas as ops.

### Funcionalidades implementadas e verificadas
- Modos Apresentador/Público (salvo no localStorage). Troca para Apresentador exige DUPLA confirmação (sem senha).
- Sessões criadas por nome + data, múltiplas simultâneas, público escolhe qual entrar. Excluir/limpar sessão.
- Grupos: adicionar/remover, nome editável, sorteio de ordem.
- Rodadas sequenciais (cada grupo no seu turno), marca acerto/erro, avança automático.
- Pontuação progressiva por faixas configuráveis (padrão R1-3=10, R4-6=20, R7-9=30). Top 3 pódio com medalhas.
- Ajudas configuráveis: Eliminar Resposta, Ajuda da Igreja, Consultar Bíblia, Dobrar Acerto (ativar antes da rodada).
- Desempate mata-mata: botões "Encerrar Empatado" e "Sortear Ganhador".
- Sons com botão mudo global. Configurações por sessão (rodadas, pontuação, ajudas).

### Observações
- NÃO há integração com Holyrics (decisão do usuário). Perguntas ficam no Holyrics, o app só controla pontuação/ajudas/desempate.
- Nome da ajuda de reforço é "Dobrar Acerto" (não "Reforço").
- Todos os textos em PT-BR.
